# Class 5 — Password audit

The audit script builds three synthetic accounts in memory, compares a small local
wordlist with unsalted MD5 digests, then measures one Argon2id verification. It
does not consume real credential dumps or access a remote host.

```sh
python3 -m venv .venv
.venv/bin/pip install -r web/requirements.txt
.venv/bin/python labs/class05/password_audit.py
```

The application hashes newly created accounts with Argon2id and upgrades a legacy
password only after a correct login. Record your own runtime and measurements in
[results.json](results.json) and discuss them in [the audit report](../../docs/password-audit.md).
The JSON is regenerated by each run; do not copy someone else's results.
